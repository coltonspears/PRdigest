Pull requests → LLM context

Turn any GitHub PR into one LLM-ready
markdown document.

Lossless. No AI summarization. The diff, review comments threaded inline next to the lines they target, linked issues, CI results — one paste-ready file.

github.com/fastapi/fastapi/pull/1
↓ change one word ↓
prdigest/fastapi/fastapi/pull/1
Try: fastapi/fastapi#1 astral-sh/uv#5000 psf/requests#6618

What you get

¶

Full context

PR title, description, author, branch, head SHA, additions and deletions. Linked issues are inlined verbatim — no clicking through.

↳

Threaded review comments

Every review comment lands directly under the line of code it targets. Replies stay grouped with their parent. Outdated comments don't get lost.

✓

Review & CI state

Approvals, change requests, and CI check results — all rendered in the same document. Your LLM sees what merged and what didn't.
